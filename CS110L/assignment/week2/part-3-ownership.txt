Example 3
---------

Code:

fn main() {
    let s1 = String::from("hello");
    let mut v = Vec::new();
    v.push(s1);
    let s2: String = v[0];
    println!("{}", s2);
}

My answer:
.push() method make ownership change.
rust donot allow index move none copy dtype in vector directly.
shall be let s2:&str = &v[0];
